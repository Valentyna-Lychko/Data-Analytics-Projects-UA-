### Tableau: Мої проєкти

У цьому розділі представлено кілька дашбордів, створених у Tableau. Всі проєкти орієнтовані на аналіз різноманітних метрик, включаючи дохід, кількість користувачів, поведінку користувачів та інші показники. У роботі були використані наступні підходи та інструменти:

1. **Обчислювані поля (Calculated Fields):** Використані для створення метрик, що забезпечують аналітичну глибину дашбордів.  
2. **LOD-вирази (Level of Detail):** Застосовані для аналізу даних на різних рівнях деталізації.  
3. **Параметри (Parameters):** Реалізовані для динамічного управління даними й гнучкого налаштування візуалізацій.  
4. **Фільтри та Filter Actions:** Інтерактивні фільтри дали можливість сегментувати дані та адаптувати відображення відповідно до аналітичних потреб.  
5. **Функції умовних виразів:** Застосовані для вдосконалення дашбордів через логічні обчислення та умовне форматування.  

У проєктах використано різноманітні типи графіків, зокрема:
- Стовпчасті діаграми (Bar Chart),  
- Лінійні графіки (Line Chart),  
- Кругові діаграми (Pie Chart),  
- Теплові карти (Heat Map),  
- Бульбашкові графіки (Bubble Chart),  
- Площинні графіки (Area Chart),  
- Деревоподібні діаграми (Tree Map),  
- Точкові графіки (Scatter Plot),  
- Діаграми з двома осями (Dual-Axis Chart).

### Дашборди

1. **Аналіз метриків доходу (Revenue Metrics Analysis)**  
   - Включає глибокий аналіз ключових бізнес-метрик, таких як загальний дохід, відтік користувачів, середній дохід на користувача (ARPPU) та інші.  
   - ![Скріншот дашборду](./revenue_metrics_analysis_screenshot.png)  
   - [Переглянути в Tableau Public](https://public.tableau.com/your_revenue_metrics_link)  

2. **Сума доходу і кількість користувачів (Revenue and Users Overview)**  
   - Показує загальний дохід та кількість користувачів із розбиттям за періодами. Включає інтерактивні фільтри для вибору часу та сегментів.  
   - ![Скріншот дашборду](./revenue_users_overview_screenshot.png)  
   - [Переглянути в Tableau Public](https://public.tableau.com/your_revenue_users_link)  

3. **Поведінка користувачів на продукті (User Behavior Overview)**  
   - Дає змогу аналізувати взаємодію користувачів із продуктом, зокрема аналіз їхньої активності та кількості сесій.  
   - ![Скріншот дашборду](./user_behavior_overview_screenshot.png)  
   - [Переглянути в Tableau Public](https://public.tableau.com/your_user_behavior_link)  

4. **Поведінка користувачів на продукті: варіант 2 (Enhanced User Behavior Dashboard)**  
   - Додано інтерактивність до інформаційної панелі за допомогою *додаткових дій* і *параметра*, який дозволяє динамічно вибирати різні метрики для аналізу (наприклад, активність користувачів, їхні сесії або періоди залученості).  
   - ![Скріншот дашборду](./enhanced_user_behavior_screenshot.png)  
   - [Переглянути в Tableau Public](https://public.tableau.com/your_enhanced_user_behavior_link)  

5. **Когортний аналіз (Cohort Analysis)**  
   - Включає аналіз утримання користувачів та їхньої активності за когортами, що допомагає виявити поведінкові тренди.  
   - ![Скріншот дашборду](./cohort_analysis_screenshot.png)  
   - [Переглянути в Tableau Public](https://public.tableau.com/your_cohort_analysis_link)
