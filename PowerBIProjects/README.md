# Power BI: Інтеграція з API для створення дашборду

## Робота з даними продажів у супермаркеті

- Використано різні функції для обчислення та агрегування даних.
- Розроблено різні типи візуалізацій для аналізу даних про продажі в супермаркеті.

---

## Опис проєкту

Цей проєкт демонструє процес створення інтерактивного дашборду в Power BI з підключенням до API. Основна мета — забезпечити автоматичне завантаження даних із зовнішнього джерела, їх трансформацію й візуалізацію в зручному форматі.

- Проаналізовано дані з Kaggle-датасету "Supermarket Sales".

---

## Опис датасету

Датасет "Supermarket Sales" містить інформацію про товари, продавців та покупців, які здійснювали транзакції в супермаркеті протягом певного періоду.  
Він призначений для аналізу популярності товарів, поведінки клієнтів і залежності продажів від дати.  
Дашборд також дозволяє змінювати валюти для зручного перегляду даних.

## Аналіз даних

- Виконано аналіз продажів за основними показниками, включаючи виручку, середню вартість товарів і кількість проданих одиниць.
- Розроблено інтерактивні візуалізації для дослідження змін у часі, категорій товарів та способів оплати.
- Додано фільтр "Currency" у форматі одиночного вибору для конвертації валют.

---

## Робота із зовнішнім API

- Підключено API Національного банку України ([bank.gov.ua](https://bank.gov.ua)).
- Отримано курс долара на останню дату.
- Використано WEB-конектор у Power BI для завантаження курсу долара.

### Джерела даних:

1. Національний банк України - [bank.gov.ua](https://bank.gov.ua)  
2. Відкриті дані - [bank.gov.ua/ua/open-data/api-dev](https://bank.gov.ua/ua/open-data/api-dev)  
3. Офіційний курс гривні до іноземних валют та облікова ціна банківських металів (формат JSON).  

---

## Робота з даними в Power BI

- Розроблено графіки та візуалізації, включаючи часові ряди, стовпчикові й кругові діаграми для аналізу даних.
- Розраховано міри для ключових метрик (загальна виручка, середня вартість товарів тощо).
- Додано нову таблицю "Currency" із двома рядками: UAH та USD.
- На дашборд додано фільтр "Currency" у форматі одиночного вибору для конвертації валют.
- Реалізовано автоматичну зміну значень графіків залежно від вибору валюти через DAX-формули.

---

### Використані DAX Формули:

#### Average Price:
```DAX
IF(
    MAX('Currency'[Currency]) = "UAH",
    AVERAGE('supermarket_sales - Sheet1 (2)'[Unit price]) * SUM(USD[rate]),
    AVERAGE('supermarket_sales - Sheet1 (2)'[Unit price])
)
```

#### Total by currency:
```DAX
IF(
    MAX('Currency'[Currency]) = "UAH",
    SUM('supermarket_sales - Sheet1 (2)'[Total]) * SUM(USD[rate]),
    SUM('supermarket_sales - Sheet1 (2)'[Total])
)
```

- Використано ці міри для графіків.

### Деталі реалізації

- **Продажі по типах оплат:** Побудовано кругову діаграму для аналізу розподілу продажів за способами оплати.  
- **Середня вартість продуктів для категорії:** Розраховано середнє значення вартості товарів у кожній категорії, створено стовпчикову діаграму для її відображення.  
- **Загальна виручка за місяць:** Розраховано загальну суму виручки для кожного місяця, побудовано лінійний графік для аналізу змін.  
- **Кількість проданих одиниць кожної категорії по містах:** Створено стовпчикову діаграму з накопиченням для аналізу розподілу продажів за містами.  
- **Обсяг продажів по датах:** Побудовано лінійний графік для аналізу динаміки продажів у часі.
