# Data-Analytics-Projects-UA-
Навчальні проєкти з аналітики даних

**Портфоліо проєктів з аналітики даних**

---

### Огляд

Цей репозиторій містить колекцію проєктів з аналітики даних, які демонструють навички роботи з SQL, інструментами візуалізації (Tableau, Power BI, Looker Studio), статистичним аналізом і сучасними платформами обробки даних. Кожен проєкт ілюструє унікальні підходи, техніки та інструменти для вирішення аналітичних завдань і створення цінної інформації.

---

### Проєкти

1. [**Метрики доходу (SQL і Tableau)**](./RevenueMetrics/)  
   Аналіз і візуалізація ключових метрик доходу з використанням SQL для обробки даних і Tableau для інтерактивних дашбордів.

2. [**SQL і Looker Studio**](./SQLLookerStudio/)  
   Підготовка даних у SQL, обчислення метрик і створення інтерактивних дашбордів у Looker Studio з акцентом на аналіз кампаній.

3. [**Tableau**](./TableauProjects/)  
   Проєкти зі створення дашбордів у Tableau, зосереджені на дизайні, інтерфейсі та інтерактивності.

4. [**Power BI**](./PowerBIProjects/)  
   Аналітичні дашборди в Power BI із фокусом на моделюванні даних та візуалізації.

5. [**Когортний аналіз (Google Sheets і Tableau)**](./CohortAnalysis/)  
   Аналіз утримання користувачів і поведінкових трендів за допомогою когортного аналізу. Використано Google Sheets для розрахунків і Tableau для візуалізації.

6. **Інші технології:**  
   Працювала з Microsoft Excel для аналізу даних, створення звітів та проведення розрахунків. Також володію Python, A/B тестуванням, а також інструментами Amplitude та BigQuery.
---

### Чому цей репозиторій?

Це портфоліо демонструє широкий спектр навичок у сфері аналітики даних — від обробки до візуалізації. Воно поєднує експертизу у використанні таких інструментів, як SQL, Tableau, Looker Studio та Python, із практичними рішеннями для бізнес-завдань.
